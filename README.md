# NoName_project

Простой mobile-first PWA shell с акцентом на UX-состояния:

- нижняя навигация с крупными touch-targets и активным состоянием;
- скелетоны загрузки для основных экранов;
- empty / error / offline шаблоны с CTA «Повторить»;
- визуальный haptic-like feedback для ключевых действий;
- safe-area и viewport-подход для iOS/Android PWA.

## Запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.
