# NoName_project

Локальный каталог дизайн-системы находится в `design-system/catalog.html`.

## Что включено
- Токены (`color`, `spacing`, `radius`, `shadow`, `motion`, `z-index`) в `design-system/tokens.css`.
- Базовые компоненты (`Button`, `Card`, `Input`, `Select`, `Tabs`, `Modal`, `Toast`, `Badge`, `Skeleton`) в `design-system/components.css`.
- Примеры всех ключевых состояний (`default`, `hover`, `focus`, `disabled`, `loading`, `error`, `success`) в `design-system/catalog.html`.
- Правила naming и composability в `design-system/architecture.md`.

## Просмотр
Откройте файл `design-system/catalog.html` в браузере.
