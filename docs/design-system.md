# Design System: визуальная концепция и базовые правила

## 1) Визуальная концепция

### 1.1 Градиенты
- Используем мягкие многоступенчатые градиенты в качестве акцентного фона и иллюстративных слоев.
- Основной бренд-градиент: `linear-gradient(135deg, #5B8CFF 0%, #7B61FF 45%, #A855F7 100%)`.
- Поверхности карточек и модалок — преимущественно однотонные, градиенты применяются дозированно (hero, CTA, пустые состояния).

### 1.2 Глубина
- Глубина формируется комбинацией:
  - elevation-теней,
  - контрастных границ (`1px`-stroke),
  - прозрачных наложений.
- Для интерактивных элементов используются уровни глубины `base -> hover -> active`.

### 1.3 Glass-слои
- Glass-слои применяются для плавающих панелей, тулбаров, toast-уведомлений.
- Базовые свойства glass:
  - фон: `rgba(255, 255, 255, 0.7)` для светлой темы / `rgba(17, 24, 39, 0.56)` для темной,
  - `backdrop-filter: blur(12px) saturate(140%)`,
  - тонкая граница: `1px solid rgba(255,255,255,0.28)`.
- Важно сохранять читабельность текста: на glass-слое контраст текста не ниже WCAG AA.

### 1.4 Контраст
- Для текста и ключевых UI-элементов целимся в WCAG AA:
  - обычный текст: минимум `4.5:1`,
  - крупный текст (>= 24px regular или >= 18.66px bold): минимум `3:1`,
  - интерактивные контуры, иконки и границы: минимум `3:1` относительно фона.

## 2) Дизайн-токены

Токены расположены в `frontend/src/shared/tokens/` и покрывают:
- цвета,
- типографику,
- отступы (spacing),
- радиусы (radius),
- тени (shadows),
- motion.

Токены должны использоваться как single source of truth и подключаться через импорт (без хардкода значений в компонентах).

## 3) Motion-правила

### 3.1 Длительности
- `fast`: `120ms` — hover/pressed feedback.
- `normal`: `200ms` — стандартные UI-переходы.
- `slow`: `320ms` — раскрытие блоков, вход/выход toast, диалоги.

### 3.2 Easing
- `standard`: `cubic-bezier(0.2, 0, 0, 1)` — основной easing.
- `emphasized`: `cubic-bezier(0.2, 0, 0, 1.2)` — акцентный вход (умеренно).
- `decelerate`: `cubic-bezier(0, 0, 0, 1)` — плавное завершение.

### 3.3 Micro-interactions
- Hover: легкое поднятие (`translateY(-1px)`) и усиление тени.
- Pressed: возврат на базовую плоскость (`translateY(0)`) + затемнение фона.
- Focus-visible: обязательный контур (`focus ring`) шириной не менее `2px`.
- Loading-состояния: скелетон-пульсация и/или spinner без резких вспышек.

### 3.4 Обязательный fallback для `prefers-reduced-motion`
- При `@media (prefers-reduced-motion: reduce)`:
  - отключаем transform-анимации перемещения,
  - снижаем длительность до `1ms` или убираем transition/animation там, где это не ломает UX,
  - оставляем мгновенные, но понятные state change (цвет/граница).

## 4) Базовые компоненты и состояния

### 4.1 Button
Варианты: `primary`, `secondary`, `ghost`, `danger`.

Состояния:
- `default` — базовые цвета и тень (для primary).
- `hover` — усиление контраста, легкое поднятие.
- `focus-visible` — заметный кольцевой контур.
- `active` — уменьшение elevation, визуальный press.
- `disabled` — пониженная насыщенность/прозрачность, `cursor: not-allowed`.
- `loading` — блок ввода, spinner слева/по центру, текст остается читаемым.

### 4.2 Card
Варианты: `elevated`, `outlined`, `glass`.

Состояния:
- `default` — базовый фон и скругление.
- `hover` — чуть больше тени и/или контраста border.
- `focus-within` — ring для карточек с интерактивным содержимым.
- `disabled` (если применимо) — визуально приглушенное состояние.

### 4.3 Badge
Варианты: `neutral`, `info`, `success`, `warning`, `danger`.

Состояния:
- `default` — компактный инлайн-индикатор.
- `hover` (для кликабельных badge) — изменение фона/границы.
- `focus-visible` — ring для доступности.
- `disabled` — сниженная контрастность, без интерактивности.

### 4.4 Skeleton
Варианты: `text`, `title`, `avatar`, `rect`.

Состояния:
- `default` — спокойный базовый цвет.
- `loading` — shimmer/pulse (без агрессивной анимации).
- `reduced-motion` — статичный placeholder без движения.

### 4.5 Toast
Варианты: `info`, `success`, `warning`, `error`.

Состояния:
- `enter` — короткое появление (opacity + небольшой translate).
- `visible` — фиксированная читаемая карточка уведомления.
- `exit` — мягкое исчезновение.
- `hover` — пауза автоскрытия (рекомендовано).
- `focus-within` — ring на action-кнопке.

## 5) WCAG AA требования (обязательные)

### 5.1 Контраст
- Текст и интерактивные элементы должны соответствовать минимуму WCAG AA.
- Любой новый color token проходит контраст-проверку на основных фонах.

### 5.2 Focus ring
- Для всех фокусируемых элементов:
  - использовать `:focus-visible`,
  - ring не менее `2px`,
  - ring должен иметь контраст >= `3:1` к соседним цветам.

### 5.3 Keyboard navigation
- Полная доступность с клавиатуры:
  - корректный tab-order,
  - видимый фокус на каждом шаге,
  - `Enter/Space` активируют кнопки,
  - `Esc` закрывает dismissible overlays/toasts/modals.
- Нельзя убирать outline без предоставления эквивалентного focus ring.
