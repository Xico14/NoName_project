# Definition of Done (DoD)

Фича считается завершённой только если выполнены все условия ниже:

- [ ] Реализованы требования задачи и acceptance criteria.
- [ ] Код прошёл code review.
- [ ] Добавлены/обновлены тесты (если применимо).
- [ ] Документация обновлена.
- [ ] Не найдено блокирующих багов.
- [ ] Выполнен accessibility-checklist из `docs/accessibility-checklist.md`.

## Accessibility gate (обязательный)

Для любой UI-задачи PR не может быть смёржен, пока не подтверждены:

- [ ] Контраст WCAG AA для текста и интерактивов.
- [ ] Видимый `focus-visible` на всех кликабельных элементах.
- [ ] Корректный tab-order и keyboard navigation.
- [ ] Семантика и ARIA у сложных компонентов (menu/dialog/tabs/status).
- [ ] Понятные и доступные паттерны ошибок форм.
