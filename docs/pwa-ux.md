# PWA Mobile UX Rules

## 1) Нижняя навигация и touch targets
- Использовать 3–5 постоянных пунктов нижней навигации для ключевых сценариев (в текущем каркасе: Главная, Каталог, Избранное, Профиль).
- Минимальный размер интерактивной области: **48x48px**, рекомендованный для primary действий: **56px+**.
- Сохранять подписи у иконок в нижней навигации для снижения когнитивной нагрузки.
- Учитывать safe-area отступ снизу (`env(safe-area-inset-bottom)`), чтобы элементы не конфликтовали с системными жестами.

## 2) Экраны состояний
В каждом data-driven экране обязателен явный state machine:
- **Loading**: skeleton, который повторяет структуру будущего контента.
- **Empty**: нейтральное сообщение + CTA (например, «Обновить» или «Создать»).
- **Error**: понятное описание проблемы и явная кнопка повторной попытки.
- **Offline**: отдельный экран или баннер с объяснением, что именно доступно без сети.

## 3) Плохая сеть и устойчивость
- Делать ограниченные ретраи (например, 3 попытки) с небольшим backoff.
- Показывать пользователю прогресс повторов: «Попытка 2 из 3».
- Хранить **последнее успешное состояние** локально (например, `localStorage`/IndexedDB + service worker cache).
- Если онлайн-запрос неуспешен, отображать кэш и помечать данные как сохранённые.
- Тексты ошибок: короткие, без техничных терминов, с понятным действием «что делать дальше».

## 4) Install-ready PWA baseline
- Должны быть: `manifest.webmanifest`, `service worker`, `theme-color`, набор иконок (`192`, `512`, maskable).
- Приложение должно открываться в `display: standalone` и иметь корректный `start_url`/`scope`.
- Для установки на Android/Desktop нужно обрабатывать `beforeinstallprompt` и показывать CTA «Установить» в подходящий момент.

## 5) Anti-patterns
- Скрывать единственный путь восстановления после ошибки (например, нет кнопки retry).
- Показывать бесконечный спиннер без состояния timeout/error.
- Использовать только иконки в навигации без текста для неоднозначных разделов.
- Делать touch targets меньше 44–48px.
- Сбрасывать контент на пустой экран при временной потере сети, если есть кэшированная версия.
